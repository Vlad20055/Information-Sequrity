Лабораторная работа №4. Асимметричная криптография. Алгоритм Мак-Элиса.

Криптосистема Мак-Элиса предложена Робертом Мак-Элисом в 1978 году. Она основана
на сложности декодирования произвольного линейного кода. Секретный ключ — код Гоппы,
для которого существует быстрый алгоритм исправления ошибок (алгоритм Паттерсона).
Открытый ключ G' = S*G*P маскирует этот код под случайный линейный код.

Шифрование: c = m*G' + z, где z — случайный вектор ошибок веса t.
Расшифрование: c*P^-1 -> исправление t ошибок -> m*S -> m = (m*S)*S^-1.

Параметры: n = 1024, k = 644, t = 38, поле GF(2^10).
